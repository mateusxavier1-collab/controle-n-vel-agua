# 💧 Sistema de Monitoramento de Nível de Água

Projeto desenvolvido em Python para simular o monitoramento de um reservatório de água no terminal.

## 🚀 Funcionalidades

* Exibição de níveis de água (1 a 5)
* Mensagens coloridas com a biblioteca colorama
* Uso de listas e funções
* Simulação automática

## 🎨 Níveis do sistema

* 🔴 Nível 1: Muito baixo (crítico)
* 🟡 Nível 2: Baixo
* 🟢 Nível 3: Médio
* 🔵 Nível 4: Alto
* 🌊 Nível 5: Muito alto (alerta)

## 🛠 Tecnologias utilizadas

* Python
* Colorama

## ▶️ Como executar

Instale a biblioteca:
pip install colorama

Execute o programa:
python monitoramento.py
